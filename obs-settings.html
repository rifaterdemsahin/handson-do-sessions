💾 OBS Settings Snapshot

Every live OBS Studio setting that powers the MacBook Pro studio — profile, scene collection, hotkeys, WebSocket bridge and the HUD script — saved into this repository so the whole studio can be rebuilt in minutes.

1. What Is In the Snapshot

The live configuration was captured from ~/Library/Application Support/obs-studio/ into the obs-settings/ folder of this repository. Downloading or cloning the repo is now enough to redeploy the complete studio.

Snapshot file Live location on macOS What it controls
global.ini obs-studio/global.ini App-wide defaults: renderer, hotkey focus behavior, dock layout, scene duplication and snapping.
user.ini obs-studio/user.ini The active user state: last profile (Untitled) and the currently open scene collection (cleanslate), UI density, vertical volume meters and NDI tally flags.
profiles/Untitled/basic.ini obs-studio/basic/profiles/Untitled/basic.ini The studio profile: output mode, 1080p60 video pipeline, audio, recording splits, WebSocket server and OBS hotkeys.
profiles/Untitled/streamEncoder.json obs-studio/basic/profiles/Untitled/streamEncoder.json Streaming encoder buffer flag captured alongside the profile.
scenes/cleanslate.json obs-studio/basic/scenes/cleanslate.json The active scene collection: camera and screen scenes, capture devices, Fade transition and the ⌥2/⌥3 scene hotkeys.
scenes/Untitled.json obs-studio/basic/scenes/Untitled.json Legacy scene collection kept as a reference (11 sources from the original studio build).
scripts/obs_indicator.py obs-studio/scripts/obs_indicator.py The HUD indicator + global hotkey manager: floating pills, audio cues, Finder/clipboard shortcuts and preview toggle.
plugin_config/obs-websocket/config.json obs-studio/plugin_config/obs-websocket/config.json WebSocket server toggle, port 4444 and auth requirement (password redacted).

Logs, profiler traces and the 56 MB Chromium browser cache under plugin_config/obs-browser were deliberately excluded — they are machine noise, not studio configuration.

🌐

2. Global Application & UI Layer

These values come from global.ini and user.ini and shape how the studio behaves before any recording starts:

  • Hotkey focus — NeverDisableHotkeys: the single most important setting. The ⌥ shortcuts fire while the browser or terminal has focus, so a take never pauses for a window switch.
  • Renderer OpenGL with macOS VSync disabled: chosen for low-latency screen capture on the MacBook Pro, restored on exit (ResetOSXVSyncOnExit=true).
  • Active scene collection cleanslate: restored automatically at launch, with the Untitled profile loaded on top of it.
  • Menu bar control — SysTrayEnabled=true: OBS can run hidden behind the take and still be reachable and controllable.
  • Confirm on exit: prevents accidentally killing OBS while a recording is live.
  • Vertical volume meters + compact UI (FontScale=10, Density=1): more channels visible on a laptop screen while monitoring the Scarlett 2i2 audio.
  • NDI tally flags on (TallyProgramEnabled): the confidence-monitor workflow can show which scene is live.
  • Snapping at 10 px, scene duplication and swap enabled: safe manual editing when building new scenes on the fly.
🎞️

3. Recording & Video Pipeline

The profile runs in Advanced output mode. Every value below lives in profiles/Untitled/basic.ini:

Setting Value Why it matters
Recording path /Users/rifaterdemsahin/Movies Recordings land in the default Movies folder, one ⌥4 away in Finder.
Container / format mp4 Direct-play files for review and upload; splits keep them crash-safe at 5-minute granularity.
Filename formatting %CCYY-%MM-%DD %hh-%mm-%ss Chronological, sortable filenames: 2026-09-18 12-39-00.mp4.
Time-based splits RecSplitFileType=Time, RecSplitFileTime=5 A new segment finalizes every 5 minutes so an interruption can never cost more than one segment. (The older 90 MB size trigger remains in the file but is inactive.)
Base / output resolution 1920x1080 → 1920x1080 Full-HD canvas for both the camera and screen scenes.
Frame rate FPSCommon=60 60 fps for smooth screen motion, cursor travel and terminal scrolling.
Scaling filter bicubic Balanced quality for any downscale of the 3456x2234 display capture.
Color pipeline NV12, Rec.709, partial range Standard broadcast-safe HD color; matches the ZV-1 footage.
Stream encoder obs_x264 Reference encoder for local streams and tests.
Audio 48 kHz stereo, CoreAudio_AAC, 160 kbps tracks Scarlett 2i2 input captured at video-standard sample rate; monitor output on the system default device.

4. The Six-Keystroke Studio

The hotkey map is split across three files — this snapshot preserves all of it end to end:

Shortcut Action Defined in
⌥+1 Start / stop recording (toggle) basic.ini → [Hotkeys]
⌥+2 Switch to the screen scene cleanslate.json → scene screen
⌥+3 Switch to the camera scene cleanslate.json → scene camera
⌥+4 Open ~/Movies in Finder (with 📁 HUD pill) obs_indicator.py (Carbon global hotkey)
⌥+5 Copy the newest recording to the clipboard (file + path) obs_indicator.py (Carbon global hotkey)
⌥+6 Bring OBS forward for a framing check / hide it again basic.ini preview hotkeys + obs_indicator.py toggle

Because HotkeyFocusType=NeverDisableHotkeys is part of the snapshot, all of these work no matter which app is in front — including inside a live coding session.

🎬

5. The Active Scene Collection: cleanslate

scenes/cleanslate.json is the collection OBS opens on launch. It is intentionally minimal — two scenes and two capture devices:

  • 📷 Scene camera (currently live): the Capture Card Device feed for talking-head takes — hooks, mental models and wrap-ups.
  • 🖥️ Scene screen: the macOS Screen Capture source for live coding, terminal traces and repository walkthroughs.
  • Transition: Fade, 300 ms — soft cuts that never jar the viewer.
  • Sources: Capture Card Device (macos-avcapture-fast) and macOS Screen Capture (screen_capture), each carrying its mute/unmute hotkey slots for future use.
  • Scene hotkeys: ⌥2 on screen, ⌥3 on camera — verified inside the JSON, not just in the UI.

The legacy Untitled.json collection (the original 11-source build) is included for reference when rebuilding PIP or multi-source scenes. The scene purposes themselves are explained in OBS Implementations & Scenes and Studio Dashboard → Footage Setup.

🔴

6. HUD Indicator & Automation Script

scripts/obs_indicator.py (455 lines) is the bridge between OBS and your eyes. It connects to the WebSocket server, listens for state changes and draws native macOS overlay pills:

  • Recording states: 🔴 red pill on start, ⏹️ stop pill on end, with Ping/Pop/Tink system sounds.
  • Scene changes: 🖥️ for the screen scene and 📷 for the camera scene, so the active source is always known without looking at OBS.
  • Global hotkeys: ⌥4 opens ~/Movies (📁 pill), ⌥5 copies the newest MP4/MKV via a dual pasteboard (real file for Finder/Slack, path text for editors), ⌥6 summons or dismisses the OBS preview.
  • Credentials: the script reads the WebSocket port and password from the obs-websocket config.json captured in this snapshot.

The script runs as the LaunchAgent com.rifaterdemsahin.obs-indicator.plist in ~/Library/LaunchAgents/, so the HUD is alive the moment you log in. Reinstalling that plist and restarting the agent is all it takes to bring the automation back on a fresh machine.

🔐

7. Credentials Were Redacted

This repository is public, so the three credential values that live in OBS configuration were replaced with REDACTED_SET_LOCALLY_WHEN_RESTORING before the snapshot was committed:

Never commit the real values. AuthSecret and AuthSalt in profiles/Untitled/basic.ini, and server_password in plugin_config/obs-websocket/config.json, authenticate every WebSocket client — including obs_indicator.py. Leaking them would let anyone on the network control OBS.

Restoring is still one step: after copying the snapshot back, open OBS → Tools → WebSocket Server Settings, set a password, and paste the same password into the restored obs-websocket/config.json. OBS regenerates the salt/secret automatically when the settings are saved. Restart the indicator LaunchAgent afterwards.

♻️

8. Backup & Restore Runbook

Capture a fresh snapshot after any studio change — copy the live files over the ones in this repo, commit and push:

OBS="$HOME/Library/Application Support/obs-studio" cp "$OBS/global.ini" obs-settings/global.ini cp "$OBS/user.ini" obs-settings/user.ini cp "$OBS/basic/profiles/Untitled/basic.ini" obs-settings/profiles/Untitled/basic.ini cp "$OBS/basic/profiles/Untitled/streamEncoder.json" obs-settings/profiles/Untitled/streamEncoder.json cp "$OBS/basic/scenes/cleanslate.json" obs-settings/scenes/cleanslate.json cp "$OBS/basic/scenes/Untitled.json" obs-settings/scenes/Untitled.json cp "$OBS/scripts/obs_indicator.py" obs-settings/scripts/obs_indicator.py cp "$OBS/plugin_config/obs-websocket/config.json" obs-settings/plugin_config/obs-websocket/config.json # Re-redact the auth values before committing, then: git add obs-settings && git commit -m "Update OBS settings snapshot" && git push

Restore the studio on a new or reinstalled machine — quit OBS first, then copy the snapshot back:

# 1. Quit OBS completely (ConfirmOnExit will get in the way otherwise) osascript -e 'quit app "OBS"' # 2. Recreate the folder structure and copy the snapshot back OBS="$HOME/Library/Application Support/obs-studio" mkdir -p "$OBS/basic/profiles/Untitled" "$OBS/basic/scenes" "$OBS/scripts" \ "$OBS/plugin_config/obs-websocket" cp obs-settings/global.ini "$OBS/global.ini" cp obs-settings/user.ini "$OBS/user.ini" cp obs-settings/profiles/Untitled/basic.ini "$OBS/basic/profiles/Untitled/basic.ini" cp obs-settings/profiles/Untitled/streamEncoder.json "$OBS/basic/profiles/Untitled/streamEncoder.json" cp obs-settings/scenes/cleanslate.json "$OBS/basic/scenes/cleanslate.json" cp obs-settings/scenes/Untitled.json "$OBS/basic/scenes/Untitled.json" cp obs-settings/scripts/obs_indicator.py "$OBS/scripts/obs_indicator.py" cp obs-settings/plugin_config/obs-websocket/config.json "$OBS/plugin_config/obs-websocket/config.json" # 3. Re-set the WebSocket password (OBS regenerates secret + salt on save), # then relaunch the HUD LaunchAgent launchctl kickstart -k gui/$(id -u)/com.rifaterdemsahin.obs-indicator

After launch, verify the three anchors: cleanslate is the open scene collection, ⌥1 records a 5-minute split into ~/Movies, and the HUD pills respond to scene changes. The screenshot-grade walkthrough of how these pieces were built lives in Step 03: OBS Implementations & Scenes.
